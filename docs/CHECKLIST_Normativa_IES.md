# Checklist — Elements del projecte i guia d'estil (IES Simarro)

## Què demana el centre

### Lliurament
| Element | Normativa | El teu estat |
|---------|-----------|--------------|
| Memòria en **PDF** | Obligatori | `Memoria_del_Projecte_PersonalBet.pdf` |
| **Full de resum** | Document separat | `Full_de_Resum_PersonalBet.pdf` |
| **USB** | Codi, presentació, figures, etc. | Carpeta `USB_Projecte_PersonalBet` (crear) |
| Full de lliurament | Formulari del centre | `Lliurament_Modul_Projecte_RELLENAT.docx` |

### Memòria — contingut mínim
| Requisit | Normativa | El teu estat |
|----------|-----------|--------------|
| **Mínim 20 pàgines** i/o **5000 paraules** | Obligatori | ~2300 paraules al MD → **CAL AMPLIAR** |
| Màxim 100 pàgines | Límit | OK |
| Portada | Títol 36pt, autor, curs, any, cicle, centre, tutor 20pt, **logotips** | Fer en Word |
| Contraportada | Resum en quadre, lletra 14 | Fer en Word |
| Pàgina 1 | Títol + autor | Fer en Word |
| Pàgina 2 | Índex numèric amb **paginació real** | Actualitzar números després d’imprimir |
| Antepenúltimes | Índex d’imatges, **contingut USB**, desglossament programari | **Falta** — afegir secció |
| Penúltima | Bibliografia (nom, autor, editorial, any) + enllaços web | Ampliar format |
| Capítols en pàgina nova | Obligatori | Word: salt de pàgina abans de cada capítol |

### Guia d'estil
| Requisit | Com fer-ho |
|----------|------------|
| Marges ≤ 3 cm | Word → Diseño de página |
| Arial o Times 11–12, interlineat simple | Estils normals |
| Capçalera | Títol projecte + secció (Capítol > Secció) |
| Peu | Nom alumne + número de pàgina |
| Índex de figures/taules | Word → Referencias → Insertar índice |
| Figures numerades + peu + referència al text | Ex.: «Figura 1. Pantalla d’inici» |
| Jerarquia | Capítol (1) > Secció (1.1) — sense més subnivells numerats |
| Redacció | Passiva o **nosaltres** (1a persona plural) |

## Accions urgents (abans de lliurar)

1. **Obrir la memòria al Word** des del PDF o MD i **ampliar** (objectius, proves, captures, USB, més desenvolupament) fins a **≥20 pàgines / 5000 paraules**.
2. Afegir **portada + contraportada + logotips** del centre i família professional.
3. Configurar **capçalera i peu** (Alberto Martí Armiñana + número pàgina).
4. Inserir **6–8 captures** de l’app + índex de figures.
5. Escriure secció **«Contingut del USB»** (antepenúltimes pàgines).
6. Copiar carpeta USB al pendrive.
7. Correu al tutor: PDF memòria + PDF full de resum (+ USB si ho demana físicament).
